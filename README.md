# The Minions

Public live view of Gru's Lab (Team Bielik's bot squad), themed as a Despicable Me-style game called The Minions.

Generated by `publish.py` from `/workspace/command-center`. Character names are assigned from the easy-to-edit mapping file `minion-names.json`. `data.json` is refreshed and the page re-renders every 60 seconds. Game stats (levels and bananas) come from real run counts. Nothing private is published here.
